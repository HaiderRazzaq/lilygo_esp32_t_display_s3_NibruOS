# NibruOS — 2FA Account Setup (Nibru-branded UI)

## ما الذي تغيّر؟

أُعيد تصميم واجهة إدخال حسابات 2FA بأسلوب متجاوب مع هوية **Nibru** الرسمية:

- ألوان الهوية المستخرجة من ملفات الشعار: `#0F1954` و`#38FFE1` و`#F1FFFD`.
- تضمين رمز الشعار الأصلي بصيغة SVG مباشرة في HTML، دون طلب صورة خارجية.
- تقسيم الإدخال إلى ثلاث خطوات واضحة: الاتصال، تفاصيل الحساب، تأكيد الاقتران.
- تحسين تجربة الاستخدام عبر الهاتف، توضيح حالات الاتصال، ورسائل النجاح والخطأ.
- إضافة رابط الهاتف `07838844400` بصيغة `tel:+9647838844400`.
- إضافة **Developed by Haider Razaq** أسفل الصفحة.
- زر مسح الحقول يمسح الآن *كل* المدخلات (الاسم، المفتاح، رمز الاقتران، وعنوان IP) ويعيد إخفاء المفتاح.
- عدم تكرار رمز الاقتران في رسالة الحالة بعد تلقيه من الجهاز.
- استقبال البيانات التسلسلية دون إنشاء تدفق `TextDecoderStream` إضافي، مع انتظار انتهاء القراءة قبل إغلاق المنفذ.

## الملفات المطلوبة للنشر

استبدل الملفات الثلاثة المناظرة في المشروع الحالي، مع الحفاظ على المسارات:

- `/account_setup.html`
- `/account_setup.css`
- `/account_setup.mjs`

لا يحتاج التصميم إلى CDN أو خدمات خارجية أو مسارات ملفات جديدة. يبقى استخدام `Fustat` اختيارياً عند توفر الخط على النظام؛ وإلا تُستعمل خطوط النظام البديلة.

**مهم:** يجب أن يستمر الخادم المحلي الأصلي بتقديم هذه الملفات واستبدال قيمة `__CSRF__` قبل إرسال الصفحة عند الحاجة. لا تغيّر نقطة النهاية `/relay` التي تستخدمها وظيفة إرسال Wi‑Fi. يتطلب Web Serial متصفحاً يدعم الواجهة (Chrome/Edge) وسياقاً آمناً مثل `localhost` أو HTTPS؛ فتح HTML بصيغة `file://` ليس طريقة التشغيل المعتمدة هنا.

## ما تم اختباره

- بنية HTML وعدم تكرار معرفات DOM المطلوبة للوظائف.
- فحص بناء JavaScript (`node --check`).
- فتح/إغلاق حقل Wi‑Fi وتبديل رؤية المفتاح ومسح الحقول والتحقق من رسائل الأخطاء داخل متصفح آلي.
- تناسق الصفحة وعدم وجود تمرير أفقي عند عروض 1440px، 768px، 390px، و320px.
- اختبارات تحليل مفتاح Base32 ورابط `otpauth`، وجولة تشفير وفك تشفير متطابقة باستخدام AES-GCM.

**لم يتم اختبار الاتصال الفعلي بلوحة ESP32، أو واجهة `/relay` الحقيقية، أو خادم المشروع الأصلي** لأن ملفات تلك الأجزاء لم تُرفق. لم تُغيّر بروتوكولات التشفير أو بنية الرسائل المرسلة للجهاز.
